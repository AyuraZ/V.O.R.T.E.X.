# V.O.R.T.E.X.

V.O.R.T.E.X. (Vetor Otimizado de Raciocínio Tecnológico Expansivo) é um projeto criativo que apresenta um universo fictício por meio do site institucional de uma empresa de tecnologia focada em inteligência artificial, pesquisa avançada e entre muitas outras tecnologias.

O projeto utiliza a estrutura de um site corporativo para contar uma narrativa aos poucos, através de páginas institucionais, documentos internos e registros de pesquisa.

## Conceito
A ideia é que o próprio site seja o meio narrativo, misturando linguagem corporativa com elementos que fogem do comum conforme o conteúdo evolui.

## Tecnologias
- HTML (estrutura inicial)
- CSS (em desenvolvimento)
- JavaScript (planejado)

## Status
Projeto em fase inicial, em constante construção.
