# V.O.R.T.E.X.

V.O.R.T.E.X. (Vetor Otimizado de Raciocínio Tecnológico Expansivo) é um projeto criativo que apresenta um universo fictício por meio de um site institucional inicial de uma empresa de tecnologia focada em inteligência artificial, pesquisas avançadas e outras tecnologias experimentais.

O projeto utiliza a estrutura de um site corporativo para contar uma narrativa aos poucos, através de páginas institucionais, documentos internos, registros de pesquisa, e experimentos interativos.

## Conceito
A ideia é introduzir esse universo fictício através de um site (por agora, mas futuramente uma aplicação web com várias interações e funcionalidades), misturando linguagem corporativa com elementos que fogem do comum conforme o conteúdo for evoluindo, sempre explorando até onde a tecnologia pode chegar e o que ela pode oferecer às pessoas.

## Tecnologias (Iniciais)
- HTML (estrutura inicial)
- CSS (em desenvolvimento)
- JavaScript (planejado)
- APIs (não-definidas)
- Banco de Dados (não-definido)
